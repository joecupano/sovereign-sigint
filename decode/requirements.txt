                   # recordings for external consumption (IQEngine, GNU
                   # Radio's SigMF blocks, other third-party tooling).
                   # Pinned deliberately: an earlier unpinned install broke
                   # sigint-ingest.py when SigMFFile.__init__() changed its
                   # keyword arguments between versions. Current API (this
                   # version) is functional-style — sigmf.fromarray(data),
                   # meta.add_capture(...), meta.tofile(...) — not the old
                   # SigMFFile(metadata_path=..., data_path=...) constructor.
                   # Bump this pin deliberately, with a smoke test against
                   # both read and write paths, not via a routine upgrade.
                   #
                   # READING stays on direct JSON parsing (see
                   # sigint-ingest.py) — do NOT reintroduce this library on
                   # the read path. Metadata is plain JSON against a
                   # documented, versioned spec; parsing it directly is the
                   # proven, dependency-free approach and avoids repeating
                   # the exact bug this pin exists to prevent.
